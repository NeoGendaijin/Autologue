# Solve These Equations

Write a Python script that solves the following equations and prints the results.

## Equations

1. Quadratic: `2x² + 5x - 3 = 0`
2. System of linear equations:
   ```
   3x + 2y = 12
   x - y = 1
   ```
3. Find the derivative of `f(x) = x³ - 4x² + 7x - 2` and evaluate at x=3

## Rules
- Use only the Python standard library (no numpy/sympy)
- Show your work step by step in the output
- Write the solution in `solve.py`
