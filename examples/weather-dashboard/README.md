# Weather Dashboard

Build a simple weather dashboard webpage.

## Requirements
- Show current weather for 3 cities: Tokyo, New York, London
- Display temperature, conditions, and an emoji icon
- Use a clean card-based layout
- Responsive design (works on mobile)
- Fetch data from a free weather API (or use mock data)

## Output
- `index.html` — the dashboard
- `style.css` — styling
- `app.js` — fetch and display logic
