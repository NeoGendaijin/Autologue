# Ping Pong Game

Create a browser-based Pong game using HTML Canvas and vanilla JavaScript.

## Requirements
- Two paddles (player vs CPU or two-player)
- Ball with physics (bounce off walls and paddles)
- Score tracking
- Game over at 10 points
- Keyboard controls (W/S for left, Arrow keys for right)

## Files
- `index.html` — game page
- `game.js` — all game logic

Keep it to a single HTML file with inline JS if possible.
