# Research Report: AI in 2025

Search the web and compile a report on the state of AI in 2025.

## Sections to Cover
1. **Top 3 Breakthroughs** — What were the biggest AI advances?
2. **Open Source vs Closed** — How did open-source models compare to proprietary ones?
3. **AI Agents** — What progress was made on autonomous AI agents?
4. **Regulation** — Any major AI laws or policies passed?

## Output
- Write the report to `report.md`
- Use markdown formatting with headers, bullet points
- Keep it concise — aim for ~500 words total
- Cite sources where possible
